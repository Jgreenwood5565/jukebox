v0.5.0, 2026-09-23 -- Modernized fork
    - Python 3.10+, Django 5.2 LTS, Django migrations instead of South,
      python-social-auth instead of django-social-auth, jQuery 3.7
    - Security: the API actually requires authentication now, per-installation
      secret key, escaped song metadata and user names in the web interface,
      skipping songs and logging out require POST
    - Dark theme (default) with light theme switch
    - Local username/password login with rate limiting, jukebox_adduser command
    - jukebox_upgrade command to convert 0.4 databases
    - Fixed login redirect, RSS feed picking a random song, infinite scrolling
      dropping filters, directory removal deleting sibling directories and
      several crashes on invalid input
v0.6.0, unreleased -- Web player
    - Listen in the browser: the server keeps the "now playing" clock and every
      listener hears the same song, skipping skips for everyone
    - Songs stream with HTTP range support at /api/v1/songs/<id>/stream
    - JUKEBOX_WEB_PLAYER=0 leaves playback to plugins as before
    - FLAC, AAC/M4A, Ogg and Opus files besides MP3
    - Tags keep their capitalization, artists, albums and genres are still
      matched ignoring case
    - Autoplay avoids songs played recently
    - FLAC and other non-MP3 files stream as 192 kbit/s MP3 converted by ffmpeg
    - Cover art from the files' tags or a cover.jpg next to them
    - Vote to skip: a song is skipped once most listeners vote, admins skip at once
    - Admins manage accounts in the web interface: add users, set passwords,
      grant admin rights, disable and delete accounts
    - Logins last 30 days instead of ending after 5 idle minutes
    - At most 3 converted streams per user at a time
    - Ready for the internet: failed logins are limited for the admin and API
      basic auth too, real client addresses behind a trusted proxy, secure
      cookies for HTTPS, password rules and a Content-Security-Policy
    - Fixed "database is locked" errors when several requests pick or record
      songs at the same time
